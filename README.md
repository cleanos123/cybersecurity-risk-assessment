# Cybersecurity Risk Assessment & Threat Modeling — Volvo Case Study

This academic cybersecurity project evaluates risks affecting a global automotive organization using a combination of risk assessment, gap analysis, threat modeling, web security analysis, and Windows endpoint hardening.

## Frameworks and Methods

- OCTAVE Allegro
- NIST SP 800-30
- NIST Cybersecurity Framework (CSF) 2.0
- STRIDE Threat Modeling
- Microsoft Threat Modeling Tool

## Project Scope

The project includes:

- Data classification and risk prioritization
- Cybersecurity gap analysis
- Supply-chain incident analysis
- STRIDE threat modeling
- Microsoft Threat Modeling Tool output
- HTTP security-header assessment
- Windows 11 hardening
- Windows Event Viewer audit logging
- Recommendations involving MFA, PAM, SIEM, EDR, segmentation, Zero Trust, backups, and vendor risk management

## My Contribution

This project was originally assigned as a group project for IS 360. I completed the primary research, technical analysis, report writing, presentation development, threat modeling, security-header analysis, Windows hardening documentation, and overall project integration.

## Key Technical Work

### Risk Assessment
Used OCTAVE Allegro as the primary asset-focused risk assessment methodology, with NIST SP 800-30 supporting threat, vulnerability, likelihood, impact, and risk analysis.

### Gap Analysis
Applied NIST CSF 2.0 to evaluate security gaps across the Govern, Identify, Protect, Detect, Respond, and Recover functions.

### Threat Modeling
Built a STRIDE-based threat model for a web-based customer portal and documented threats affecting authentication, APIs, databases, and trust boundaries.

### Web Security Analysis
Reviewed HTTP security headers and identified risks associated with missing controls such as Content-Security-Policy, X-Frame-Options, Referrer-Policy, and Permissions-Policy.

### Windows Hardening
Documented Windows 11 hardening activities including:

- Windows Defender
- Windows Firewall
- Windows Update
- Account lockout policies
- Disabling unused accounts
- BitLocker encryption
- Windows Event Viewer audit logging
